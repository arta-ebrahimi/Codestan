# 🇮🇷 Codestan | کُدستان

### Learn to Code. Build Your Future.

کُدستان یک پلتفرم آموزش برنامه‌نویسی است که با هدف ایجاد تجربه‌ای مدرن، ساده و کاربردی برای یادگیری مهارت‌های برنامه‌نویسی توسعه داده می‌شود.

هدف ما فراهم کردن بستری مناسب برای یادگیری، پیشرفت و تبدیل ایده‌ها به پروژه‌های واقعی است.

## ✨ What is Codestan?

کُدستان تلاش می‌کند مسیر یادگیری برنامه‌نویسی را ساده‌تر و جذاب‌تر کند.

### 🎯 Our Mission

- ارائه آموزش‌های کاربردی برنامه‌نویسی
- ایجاد محیطی مدرن و کاربرپسند
- کمک به رشد مهارت‌های فنی
- فراهم کردن فرصت ساخت پروژه‌های واقعی

### 🛠️ Technologies
